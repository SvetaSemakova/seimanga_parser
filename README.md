# Парсер манги: прямые URL + первые главы
Простой парсер манги из прямых URL и сохранение в MySQL.

Что здесь реально нужно:
- открыть страницу манги из urls.txt;
- получить метаданные;
- собрать ссылки на главы;
- скачать первую главу или N глав;
- сохранить картинку, персонажей и главы в локальные папки;
- записать данные в MySQL.

## 1. urls.txt
Указывайте прямые ссылки на страницы манги, по одной на строку:

    https://a.zazaza.me/nana__A5327
    https://1.seimanga.me/chelovek_benzopila

Также поддерживается старый формат `zazaza;URL` / `seimanga;URL`.

## 2. Виртуальное окружение

Перед установкой зависимостей рекомендуется создать и активировать виртуальное окружение.

**Windows (PowerShell):**

    python -m venv venv
    venv\Scripts\Activate.ps1

**Windows (cmd):**

    python -m venv venv
    venv\Scripts\activate.bat

**Linux / macOS:**

    python3 -m venv venv
    source venv/bin/activate

После активации в начале строки терминала появится `(venv)` — это значит, что окружение подключено. Все последующие команды (`pip install`, `python parse_manga_to_mysql.py`) нужно выполнять именно в этом окружении.

Для выхода из окружения используйте команду `deactivate`.

## 3. Запуск

    python -m pip install -r requirements.txt
    python parse_manga_to_mysql.py

По умолчанию скачивается только первая глава каждой манги. Для другого количества измените последнюю строку файла:

    run("urls.txt", chapters_count=10)

## 4. Изображения и главы 

Для ZazaZa/SeiManga некоторые главы закрыты возрастным предупреждением. Для такой главы обычный URL может содержать только сообщение с подтверждением. Парсер автоматически распознаёт такую страницу и повторяет запрос с параметром `?mtr=true` — именно на этот URL сайт переводит после нажатия «продолжить чтение». Вложенные query-параметры сохраняются корректно.

При успешном доступе в `manifest.json` сохраняются и исходный URL главы, и фактический `access_url`, использованный для чтения.

Selenium оставлен только последним резервным вариантом для ридеров, где изображения действительно появляются исключительно после JavaScript-рендеринга; для обычных ZazaZa 18+ глав он не требуется.

## 5. MySQL

Если MySQL недоступен, это не остановит скачивание глав после успешного чтения страницы манги.

## 6. Связи таблиц MySQL

При запуске автоматически создаются связанные таблицы:

- `manga` — основная информация о манге;
- `chapters` — главы, связанные с `manga.id` через `manga_id`;
- `pages` — страницы, связанные с `chapters.id` через `chapter_id`;
- `characters` — персонажи, связанные с `manga.id` через `manga_id`.

В `pages` сохраняются URL страницы и локальный путь к скачанному файлу. Обложки и изображения персонажей по-прежнему сохраняются локально. Поле `manga.chapters_count` содержит общее количество найденных глав, но файлы страниц по умолчанию скачиваются только для первой.

Все новые каталоги и имена файлов создаются латиницей: русские названия транслитерируются (`Клинок, рассекающий демонов` -> `Klinok_rassekayuschiy_demonov`). Названия в базе данных и `manifest.json` сохраняются без изменений.
